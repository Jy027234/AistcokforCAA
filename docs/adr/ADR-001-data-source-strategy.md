# ADR-001：数据源策略——免费优先、前向归档、显式降级

**状态：已采纳（待用户确认权利条款）**
**日期：2026-09-13**
**决策者：用户（"数据源暂不考虑付费，尽量用免费的高质量来源，也可以考虑网络抓取"）+ 工程实现**

## 背景

主文档 §6 要求 M0 完成数据源验证与许可清单。用户明确选择免费路线。
T4 实测发现三项决定性事实：

1. 免费行情源**不提供历史时点版本**，且前复权序列会随后续分红重算；
2. 免费源会**按出口 IP 长时段封锁**（东财实测 30 分钟以上未恢复）；
3. 交易所与巨潮的公告页面**自带发布时间**，是本项目目前唯一可获得的时点证据。

## 决策

1. **不依赖任何单一免费源。** 每个能力域至少两个独立候选，按优先级降级。
2. **降级必须显式。** 降级产生 degraded 标志与归档留痕；禁止静默混接多源
   （assert_no_silent_mix），切换来源需新数据版本与差异报告（§6.3）。
3. **前向归档从接入第一天启动。** 每次抓取记录原始字节、first_seen_at 与内容哈希，
   由此积累 LIVE_OBSERVED 记录。这是本项目获得可证明时点数据的**唯一**途径。
4. **事件归档优先走官方渠道**（上交所/深交所/巨潮），而非第三方聚合。
5. **正式历史 PIT 回测与 F07–F10 财务因子默认关闭**，直到具备可证明时点依据。

## 后果

- ✅ 项目可在无付费合同下推进价格研究与事件研究。
- ✅ 具备抗单点失效能力（已实跑验证）。
- ⚠️ **不能**声称具备完整历史因果/收益验证能力。项目标识与范围必须相应收窄
  （主文档 §19 已预置该情形）。
- ⚠️ 前向归档的时间价值随时间衰减：越晚启动，缺失的历史越长。因此本决策有紧迫性。
- ⚠️ 所有源的权利状态目前为 UNKNOWN，**不得进入模型外发链路**（§17.2）。
