# ADR-003：M0 范围收窄——价格研究 + 前向事件观察

**状态：已采纳**
**日期：2026-09-13**

## 背景

T4 实测确认：免费数据源不提供历史时点（PIT）版本。三条证据：

1. 行情接口无 as-of / 修订版本参数，返回体只含序列本身；
2. 前复权序列以最新除权基准重算，**未来分红会改变历史数值**（正是 D06 要防的）；
3. 财务接口只返回当前修订版，无法取得"某次修订当时可见的值"。

## 决策

按主文档 §19 预置的兜底条款收窄 M0 范围：

| 能力 | 决定 |
|---|---|
| 证券身份、行情、快照、有限模拟账本 | ✅ 保留 |
| S1 价格类基线（F01/F02/F04/F05/F06） | ✅ 保留 |
| 事件归档与研究卡 | ✅ 保留，且优先走官方渠道 |
| F07–F10（PIT 财务） | ❌ 默认关闭（`pit_dependent_factors_enabled: false`） |
| 历史财务回测 | ❌ 不启用 |
| "历史因果验证"类结论 | ❌ 不得声称 |
| 前向观察（LIVE_OBSERVED） | ✅ **必须立即启动** |

## 后果

- 项目可继续推进，但**对外表述必须同步收窄**：这是价格研究与前向观察系统，
  不是历史因果验证系统。主文档 §19 明确要求"不能在不改标识、不改范围的情况下继续声称"。
- 未来若获得带 PIT 的数据源，可用**同一批黄金用例**重跑验证后解除限制——
  验收用例不因数据源替换而改变（v0.2.2 §4.3）。
