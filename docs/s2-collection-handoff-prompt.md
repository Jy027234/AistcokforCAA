# S2 数据采集实施交接提示词

将下方内容连同 `docs/s2-collection-implementation-plan-20260928.md` 一起交给实施 AI；跨机器时也提供相关源码和文档。原始 PDF/SQLite/部分证据被 Git 忽略，不能假定 clone 后存在。

---

请依据 `docs/s2-collection-implementation-plan-20260928.md` 完成 S2 数据采集与正式可用链路。先核对当前仓库、主规格及已有变更，复用现有组件。方案的核对基线是 2026-09-28、提交 `1a02623b`；不需要回退到该提交。

目标是让产品从官方财报获得可追溯的五类绝对金额和同日市值，经过真实验证与版本处理后，能在明确范围内计算完整 F07—F10 及 S2 排名，并持续增量更新。仅多产出候选 JSON 不算完成。

按三个完整交付包推进：

1. **A：前向可用。** 打通原有八股固定范围的发现、归档、验证、正式入库、匹配快照及产品读取。使用 300502 验证额外版式。完整合格者产生因子及同池排名，601012 等规则排除如实列出，不为凑齐信号改公式。
2. **B：覆盖与增量。** 读取当前配置池，制造业先扩展，再覆盖适用的其他非金融证券；金融单列不支持。实现公司级共享索引、动态期间、缓存、水位、有限重试、备源与恢复，每只股票有结果，合格范围接入已有调度。
3. **C：历史重建。** 按主规格支持独立的历史证据模式，在原版档案、修订、历史市值和池定义可证明的有限区间回放；缺失项限制对应历史范围，不阻断已完成的前向使用。

关键约束：

- 已有可用路线是巨潮，加已验证样本的深交所 `POST /api/search/content` 备源。上交所探索限定预算，无明确协议就回退巨潮，不反复猜接口拖住交付。Tushare 付费路径不使用。
- 用 `required_s2_periods()` 生成需求，不把 2026H1 五期写死。2026H1 当前需要 16 个指标—期间值；普通工商模板不是仅制造业模板。
- 程序承担查询和已知表格提取；模型只处理必要的未知版式和修订说明，输出原文定位，不猜数。模型调用有缓存和有限预算，不增加付费服务。
- 新增可复核的机器验证证据协议，同时更新升仓与读侧，保留旧人工协议。正常样本自动处理，无法消除的歧义进入人工异常队列。禁止模型冒签 `HUMAN_VISUAL` 或人类 reviewer。
- 同一公司的全类别公告索引只扫描并处置一次，多个期间共享；保留有边界的修订核查结论和版本链。后发比较列不能冒充旧时点原值。
- 同站/跨站相同 PDF 哈希不是独立数值验证。原文身份、期间、合并口径、单位、累计性质与字段定位必须校验；部分更正通过明确版本包支持，不能伪造共同原文哈希或任意逐字段拼源。
- 前向模式保留真实首见及校验时间。历史模式保留今天首见，但根据真实原始档案重建历史可用时间；修正现有 readiness 的无条件首见过滤须按模式分支，不能全局去掉时间限制。
- 财报只按新公告/修订增量更新；市值按交易日采集并与目标快照匹配。北京时间判断日历和 cutoff。缺失、错日、未知可用依据不能用零值/当前数据补齐。
- 明确已验证证券范围；不以静态全局开关强行启用 S2。不把全市场零缺口或建议覆盖率变成首批可用的额外前置条件，也不隐去失败证券缩小统计分母。

可自主处理常规可逆实现选择。只在真实阻断时纳入必要修复，其他改善记入已有待办。每个工作包完成实现后集中做针对性验证，复用有效测试与归档证据；不要每次小改都跑全套，也不要反复实盘全量抓取。适用仓库门禁照常执行。

需要分工时可使用子 agent，独立工作包明确文件归属；共享域名限速和模型预算，避免多代理重复抓取。模型选择遵循当前用户设置，不强制所有任务都用 Luna max。浏览器操作遵守当前 AGENTS 的桌面隔离规则，数据任务优先 CLI/API。

保护已有运行数据、数据库及进程使用中的锁。不要把原始数据、密钥、缓存或他人修改一起提交。先完成本地实现与适用验收；提交、推送和部署仅在本对话已有相应授权时执行。

交付时给出最终实际命令、代码/协议变更、适用验证结果、归档证据位置、覆盖报告及具体缺口。重点报告正式事实数、完整四因子股票数、S2 排名股票数、当前可用范围和历史可回放范围，并说明未验证的线上状态。完成上述范围后结束，不继续扩展新策略或无限探针。
