# 产品数据需求与降级矩阵

**状态：已采用**
**更新：2026-09-22（北京时间）**

本矩阵从产品功能反推数据必要性。原则是：只让缺失数据阻断它实际支撑的功能；
不把 S2、F10 或 AI 证据的缺失误报成整个 S1 模拟不可用，也不以估算值、零值或
当前修订值伪装成历史决策数据。

## 数据源筛选结论

1. **腾讯收盘快照作为总市值主路径。** 对研究池分批请求，字段 30 校验行情日，
   字段 45 取总市值（亿元）；每批保存原始响应收据与哈希，再生成批次清单收据。
   2026-09-22 实跑覆盖 900/900。
2. **东方财富作为显式备源。** `f20` 可提供总市值，但接口会把超大页面静默截断
   到 100 条，且存在远端主动断开。备源已改为显式分页、总条数一致性检查和证券
   冲突拒绝；任何一页失败都不发布部分市场。
3. **交易所和巨潮优先承担证据与修订职责。** 它们适合公司行为、公告时间、原文
   与未来 XBRL 财务事实，不用来替代高频行情源。
4. **Sina 财务和 mootdx 继续只作受限探针/交叉核对。** 前者权利不满足生产使用，
   后者缺完整修订链且有零值歧义；均不能静默回填 S2。
5. **Tushare Pro 已排除。** 必需财务接口需要付费权限，与当前免费路线不符。

## 运行门禁

- 当前快照的行情、行业、复权窗口和模拟价格通过时，S1 可以运行。
- 总市值或财务数据缺失只把快照标记为增强能力降级，并关闭对应 F10/S2 输出。
- AI 输出必须引用决策时点可见的证据；没有可定位原文时，只能陈述缺口，不能补写事实。
- 任一来源切换都记录 `source_id`、观察时间、原始收据与内容哈希；禁止逐字段静默混接。
